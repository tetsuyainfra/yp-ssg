# YP-SSG
Yellow page for peercast-root on SSG(StaticSiteGenerator)
genreated by 11ty(eleventy)


# how to build
```shell
# Install mise
$ cd yp-ssg
# create venv automatically

# build/serve
$ npm run build
$ npm run serve

# format
$ npm run format:check
$ npm run format:fix

# lint

```
